# Shelf Snap

A Flutter app that turns a photo of a bookshelf into a searchable digital library. Point the camera at your shelf, and Shelf Snap OCRs the spines, uses Gemini to reconstruct the fragmented/garbled text into real book titles and authors, then looks each one up and lets you save matches to your library.

## How it works

1. **Capture** — the scanner screen takes a photo of the shelf and runs on-device OCR ([google_mlkit_text_recognition](https://pub.dev/packages/google_mlkit_text_recognition)) to pull raw text blocks off the spines.
2. **Identify** — the OCR blocks (with their bounding boxes) are sent to a self-hosted Gemini-backed API, which groups fragments into individual books and infers their real titles/authors.
3. **Search + score** — each identified book is searched against the Google Books API and candidates are ranked by similarity to filter out weak/false matches.
4. **Save** — confirmed matches can be added to one of the user's libraries, with genre alerts available for books added into watched genres.

## Project structure

```
lib/
  core/               # Shared models/services used across features
  features/
    auth/             # Firebase Auth sign-in/sign-up flow
    home/             # Bottom-nav shell and home screen
    library/          # Library CRUD (models, providers, repository)
    scanner/           # Camera capture, OCR, book identification, matching
  firebase_options.dart  # Generated by `flutterfire configure`
  main.dart
```

## Tech stack

- **Flutter** with **Riverpod** for state management
- **Firebase** (Auth, Cloud Firestore) for user accounts and library storage
- **Google ML Kit** for on-device text recognition
- **Google Books API** for candidate book search
- A self-hosted Gemini-backed Node.js API for grouping OCR fragments into books

## Getting started

### Prerequisites

- [Flutter SDK](https://docs.flutter.dev/get-started/install) (see `environment.sdk` in `pubspec.yaml`)
- A configured Firebase project (`flutterfire configure` generates `lib/firebase_options.dart`)

### Setup

1. Install dependencies:
   ```
   flutter pub get
   ```
2. Create a `.env` file in the project root with any required API keys, e.g.:
   ```
   GOOGLE_BOOKS_API_KEY=your_key_here
   ```
3. Run the app:
   ```
   flutter run
   ```

### Useful commands

```
flutter analyze   # static analysis
flutter test      # run tests
```
